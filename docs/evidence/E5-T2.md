**Date:** 2026-11-25 · **Owner:** agent · **Status:** `VERIFIED-LOCAL`
(acceptance `npm audit --omit=dev --audit-level=critical` is green; CI-only

## Real boundary

`docs/evidence/E5-T1.md` classified all 41 advisories. The only shipped-source
high with a non-major fix was `zod` → `4.6.7`. The remaining safe fixes were
transitive or dev-tool patches. `expo-router@58.0.32` and `expo@52.0.49` are
semver-major and were **not** applied. `--force` was never used.

This repair was only possible after Sprint 69 removed runtime Zod from the
common login chunk. With the old graph, `zod@4.6.7` raised login transfer to
765,137 B and failed the unchanged ratchet; that attempt was reverted, not
waved through.

## Commands

```bash
npm install --save-exact zod@4.6.7
npm audit fix                 # no --force
npm audit --json
npm run build
npm run perf:login-route
```

suppressed.
