## What was measured

```bash
npm audit --json > /tmp/opencode/audit-e5.json
npm ls --omit=dev --all --json > /tmp/opencode/prodtree-e5.json
```

The audit exits non-zero while advisories remain; that is expected and is not
suppressed. The counts at this tree are **41 advisories: 0 critical, 19 high,
20 moderate, 2 low, 0 info**. No secret value is present in this evidence.

## Classification method

1. **S1 — direct app import:** the package name appears in a real `import`,
   `import()` or `require()` in `app/`, `screens/`, `components/`, `lib/`,
   `src/` or `store/`. These are reachable shipped source.
2. **S2 — runtime dependency tree, no direct app import:** present in
   `npm ls --omit=dev` but not directly imported by app source. This is a
   dependency-graph classification, **not** proof of browser bundle execution
   or exploitability. Bundle membership is not claimed for S2 rows.
3. **B1 — direct dev dependency:** declared in `devDependencies`.
4. **B2 — dev transitive:** neither in the `--omit=dev` tree nor a direct dev
   dependency.

`fix` reports npm's own `fixAvailable`: `semver-compatible` means a non-major
fix exists; a named `name@version (major)` is a breaking upgrade; `none` means
npm has no fix in the current dependency range.

### Direct shipped source (S1)

| Package | Severity | Fix | Advisory (short) |
|---|---|---|---|
| `expo-router` | high | `expo-router@58.0.32` (**major**) | `query-string` → `decode-uri-component` DoS |
| `zod` | high | `zod@4.6.7` (non-major) | memory exhaustion on oversized constrained collections |
| `react-native-markdown-display` | moderate | none | transitive `markdown-it` uncontrolled resource consumption |

**Reading:** the only S1 high with a non-major fix is `zod`. The `expo-router`
fix is a major SDK jump inside a login bundle with **28 B** of headroom, so it
is not a safe targeted fix under the current ratchet. The unfixable moderate
sits in the markdown renderer; no claim is made that the advisory is exploitable
in the current renderer configuration.

### High advisories with no fix in the current range

`linkify-it`, `markdown-it`, and `react-native-markdown-display` (the last is
the direct wrapper around `markdown-it`). These require a separate design
decision or an override; no fix is silently fabricated here.

### High advisories that require a major upgrade

`decode-uri-component`, `expo-router`, and `query-string` all resolve only via
`expo-router@58.0.32`, a semver-major upgrade. This is recorded as blocked by
the SDK 57 / login-ratchet ceiling, not deferred as "done".

- **Not safe:** `npm audit fix --force`, which would force `expo-router@58` and
  break the SDK 57 / 733,000 B ceiling.
- **Unresolved by npm:** the three no-fix advisories listed above remain open
  until a renderer/override decision is made.
- **GT-12 remains authoritative:** production audit still has 0 critical; this
  classification does not change that gate or claim zero vulnerabilities.
