# E2-T4 — Playwright traces uploaded on failure

The `real-stack` CI job in `.github/workflows/ci.yml` contains:

```yaml
- name: Upload Playwright traces on failure
  if: failure()
  uses: actions/upload-artifact@v4
  with:
    name: playwright-traces
    path: test-results/
    if-no-files-found: ignore
```

It sits after the "Real-stack e2e walkthrough" step, so a failed e2e run uploads `test-results/`.
`if-no-files-found: ignore` prevents a cosmetic failure when the runner stops before writing a
trace. Verified by reading the committed workflow and by the green PR #23 run
<https://github.com/dmuhoro/EasyTutor/actions/runs/45566265809> (the step is skipped on success,
as designed).
