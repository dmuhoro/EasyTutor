A component weighing 240 N rests on an inclined steel plane angled at θ = 25° to the horizontal. If the static coefficient of friction is μs = 0.35, determine the minimum force P applied parallel to the incline required to prevent the component from sliding down.

architecture FIGURE 3.1 — FREE BODY DIAGRAM (FBD) Equilibrium State (ΣF = 0)

For impending downward slide under limiting static equilibrium along the plane:

ΣFy' = Rn - W·cos(θ) = 0 Ff = μs · Rn ΣFx' = P + Ff - W·sin(θ) = 0

Step 02 • Available Max Static Friction Ff = μs · Rn

Step 03 • Gravitational Force Downward Incline W|| = W · sin(θ)
Wdown = 240 × sin(25°) = 240 × 0.4226
⇒ Wdown = 101.43 N
Step 04 • Minimum Applied Hold Force (P_min) P + Ff ≥ Wdown
Pmin = Wdown - Ff = 101.43 N - 76.13 N
Pmin = 25.30 N Matches Option B (~24.8 N rounded standard)
