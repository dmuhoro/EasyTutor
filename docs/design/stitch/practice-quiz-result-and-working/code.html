B. 196.2 N — Exact threshold limiting friction reached.

Applied Engineering Mechanics Newtonian Statics

Determine the minimum horizontal pull force required to overcome static friction for a 50 kg steel crate on a clean industrial shop floor (μs = 0.40, g = 9.81 m/s²).

1 Weight Calculation
F_g = m · g

W = m × g = 50 kg × 9.81 m/s² = 490.5 N

Downward gravitational load exerted uniformly on the horizontal workbench surface.

2 Normal Contact Reaction
ΣF_y = 0

N = W = 490.5 N

Equilibrium maintained along the vertical plane with zero vertical acceleration (ay = 0).

3 Limiting Static Resistance
F_max = μ_s · N

F = μ × N = 0.4 × 490.5 N = 196.2 N

Traction threshold required to overcome dry surface contact asperities and initiate impending motion.
