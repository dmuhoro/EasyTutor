# AI Learning Contract

Logical responsibilities (not separate agents now): Socratic Tutor, Curriculum Guide, Assessment Designer, Learning Analyst, Research Assistant, Project Mentor.

AI may: ask diagnostic questions, surface misconceptions, adjust hints, generate appropriately challenging exercises, explain errors, encourage reasoning/attempts, recommend review, ground curriculum explanations in authorized sources.

AI must not: arbitrarily award mastery, fabricate learner state, claim verification it lacks, or replace deterministic progress logic. All AI recommendations are advisory; deterministic domain confirms mastery.

AI outputs carry provenance (cache/local/cloud/offline_fallback) already in `lib/ai/reliability.ts`.
