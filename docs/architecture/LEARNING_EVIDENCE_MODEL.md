# Learning Evidence Model

Evidence records carry: learnerId, skillId, activityId, assessment method, correctness/quality, hints, attempts, independence, timestamp, context, reasoning, feedback, provenance (verified/sourced/ai-generated). Methods: mcq, short_answer, explanation, worked_solution, practical, portfolio, oral, transfer_task. Weights differ by method and independence; assisted performance down-weighted. History preserved; contradictory evidence can revise judgement.
